# AI & Machine Learning Portfolio

A responsive, dependency-free portfolio site built with HTML, CSS, and a small amount of JavaScript.

## Run locally

Open `index.html` in a browser. No build step is required.

## Personalize

The page is set up with Zachary Steuer's name and Austin, TX location. Replace `hello@example.com` with the email address you want to publish, and replace `yourusername` in the GitHub and LinkedIn links. The three project cards are starter examples; update their titles, summaries, tools, and links to describe your actual work. Update the Toolbox skills to match your experience.

The visual cards are original CSS/SVG compositions and do not require image assets. Project filters and mobile navigation are implemented in `script.js`.
