# AI & Machine Learning Portfolio

A responsive, dependency-free portfolio site built with HTML, CSS, and a small amount of JavaScript.

## Run locally

Open `index.html` in a browser. No build step is required.

## Personalize

Search the files for `Your Name`, `hello@example.com`, `yourusername`, and `YOUR CITY`. Replace those placeholders with your details. In `index.html`, update the three starter project cards with your real project summaries, tools, and links. The visual cards are original CSS/SVG compositions, so they do not require image assets.

Update the skills in the Toolbox section of `index.html` to match your experience. The project filters and mobile navigation are implemented in `script.js`.
